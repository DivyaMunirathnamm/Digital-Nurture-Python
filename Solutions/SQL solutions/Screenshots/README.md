
# SQL Output Screenshots

This folder contains selected screenshots of SQL query execution and results completed during the Cognizant Digital Nurture 5.0 training program.

Only a sample collection of screenshots has been uploaded to keep the repository organized and easy to navigate. The screenshots demonstrate various SQL concepts including:

* SELECT Statements
* Filtering and Sorting
* Aggregate Functions
* GROUP BY and HAVING
* Joins
* Subqueries
* Database Operations

These screenshots serve as examples of successful query execution and are not intended to represent every SQL exercise completed.

For the complete SQL scripts and solutions, please refer to the SQL Solutions folder.
